Examples of what belongs here:
- Auth: JWT tokens stored in Authorization header, 24h expiry
- Errors: All API errors return { error: string, code: string, statusCode: number }
- Tests: Use vitest not jest; test files in __tests__/ sibling to source
- Python: Virtual env at .venv/, activate before running pytest
- Imports: Use path aliases (@/lib/...) not relative ../../ imports
- DB: Never call db.query() directly — use the repository layer in src/db/
